# Telegram-бот для вывода учебного расписания в мессенджере с использованием парсинга
Telegram-бот для просмотра расписания учебных занятий согласно данным с официального сайта ИрНИТУ посредством парсинга. 

Вместо того, чтобы открывать браузер, заходить на официальный сайт ВУЗа, открывать вкладку с расписанием, искать свой институт, а потом группу, за вас это может сделать простой алгоритм, для активации которого вам понадобится нажать только одну кнопку в чат-боте.

Был разработан ещё в мае 2026 года, однако было создан новый репозиторий с чистой историей commit'ов во избежание компрометации хоть и давным-давно отозванных,  но уязвимых данных.

---

Первичное меню для взаимодействия с пользователем:
 1. `📅 Получить расписание` кнопка для перехода к выбору формата вывода расписания
 2. `🔄 Сменить группу` кнопка для смены группы с последующим подтверждением
 3. `ℹ️ Моя группа` кнопка для вывода информации о текущей выбранной группе
 4. `🤖 Информация о боте` кнопка для вывода информации о боте

Меню для выбора формата вывода расписания:
 1. `🍎 На неделю` выводит непосредственно расписание согласно текущей неделе. Расписание на каждый конкретный день выводится в отдельном сообщении
 2. `👇 На сегодня` выводит расписание только на сегодняшний день
 3. `👉 На завтра` выводит расписание на завтрашний день
 4. `🍏 На следующую неделю` выводит расписание на следующую неделю
 5. `🔄 Сменить группу` кнопка для смены группы с последующим подтверждением
 6. `◀️ Назад` кнопка для возвращения в первичное меню
